## Discrepancies found (current v9.2 tex already violates the brief)

Line numbers refer to `gain-over-copy-paper.tex` as read in this pass.

- **D1 — "pretraining exposure" appears twice, both in violation of brief §4.10/§8.**
  Line 62: *"the non-trivial raw scores ($0.151$--$0.375$ across models) reflect partial
  pretraining exposure rather than a genuinely unseen domain"*. Line 314 repeats the same
  unsupported causal claim in the results section: *"The low raw score is consistent with a
  domain only partially covered by pretraining (the corpus is public, so some exposure is
  expected; \S\ref{sec:intro})."* The study measures raw (unaided) recall; it does not
  establish memorisation, contamination or pretraining exposure. Brief 4.10 requires removing
  "reflect partial pretraining exposure" outright. Both sentences must be rewritten to state
  only that raw recall is non-trivial, without a causal claim about why — line 314's version is
  the more load-bearing of the two, since it sits directly beside the Gemini 3.7 Flash headline
  numbers a reader is most likely to quote.

- **D2 — "human-judged" is not used verbatim, but the production-study framing risks the same
  misreading.** No literal string "human-judged" occurs in the tex (checked), so this is not a
  live violation, but §sec:live and §sec:judgefamily should be checked in the v10 draft to
  ensure no reader infers a human panel: both judges (`gpt-4.1`, `claude-opus-4-6`) are models.
  Flagging pre-emptively since brief 4.9/§8 singles this phrase out and the current text's
  repeated "judged quality" phrasing is one word away from the banned form.

- **D3 — "verified irrelevant" does not appear verbatim**, but the *irrelevant* control arm
  name (§sec:ceiling-controls, line 191, and Table `tab:controls`) is defined only by
  seed-IRI disjointness, which the tex itself concedes (line 530, §sec:controls "What the
  placebo guarantees") is a construction guarantee, not answer disjointness. The arm's own
  name risks reading as "verified irrelevant" to a skimming reader. Brief §8 bans the phrase;
  the v10 draft should keep the tex's own qualifying sentence (line 530) directly adjacent to
  every occurrence of the arm name in results prose, not only in the limitations section.

- **D4 — "private/unseen corpus" language.** Line 62 states *"what makes it a useful test bed
  is that it is organisation-controlled and curated, not that it is hidden"* and line 92 calls
  the corpus a "curated corpus" — these are compliant. But §sec:related (line 77) quotes
  GraphRAG's framing of *"private and/or previously unseen"* collections in a way that, read
  in isolation, could be mistaken for this paper's own characterisation. Not a violation in
  itself (it is an attributed quote about other work), but the v10 draft should make sure the
  surrounding sentence keeps the attribution unambiguous, since brief §8 bans this phrase for
  the paper's *own* corpus description and §2 requires the corpus's actual (LLM-derived,
  author-directed) provenance to be stated plainly, not implied to be a "private/unseen"
  research asset.

- **D5 — Denominators mixed: 0.964 vs 0.933 already flagged, but check every restatement.**
  Line 314 states both explicitly and correctly labels them as non-interchangeable ("That
  macro ceiling is not the item-pooled exposed fraction, $0.933$"), and line 841 in
  §sec:limits repeats the correct distinction with the full derivation
  ($10{,}600/11{,}360=0.933$). No violation found in the current tex — both instances already
  comply with brief 4.5. Recorded here as confirmation, not a defect, so the v10 editor does
  not re-flag it needlessly.

- **D6 — "0/760" risk: the n01 census (3 units, all failing adjudication) must never be written
  as "0/760".** The tex is currently careful: line 484 says "the comparison is 71 of 760 bare
  against 0 of 760 grounded" — this 0/760 refers to the **grounded arm's relationally-validated
  recovery of unexposed items** (a real, correctly-denominated statistic, derived from the
  grounded arm's 3 raw credits all failing adjudication, 3/760 → 0/760 after adjudication), and
  is distinct from the abstract's "three unexposed items recovered" claim in
  §sec:tenmodel/§sec:audit (which is the pooled sweep's n01=3, denominator 11,360, not 760).
  These are two different studies on two different denominators (the sweep's n01 census, and
  the suppression section's per-model unexposed-item-slot count) that happen to produce
  superficially similar-looking "0" and "3" figures. **No current tex line conflates them**,
  but because both numbers involve "3" and "0" on differently-scaled denominators (11,360 vs
  760), the v10 draft is at high risk of an editing-pass error that merges them. Row 8/9 (sweep
  n01=3/11,360) and row 16/17 (suppression 92→71/760, 3→0/760) in the ledger above must stay
  visibly separate artefacts in any rewrite.
