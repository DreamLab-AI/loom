## Divergences (documented, EXP-007-driven)

1. **`embed`/`nearest` are NOT `?`-propagated** (the §6 sketch uses `?`). They are
   ACCELERATOR calls: an error degrades to a NoMatch `Scaffold` (fail-open), never
   a 5xx. Only the lexical floor (`seeds`/`assemble`) propagates. Assertion 5 pins this.
2. **Fallback default OFF** — `LOOM_SEMANTIC_FALLBACK=0` and `LOOM_SEMANTIC_MIN_INJECT`
   unset ⇒ no semantic candidate can inject even if the switch is on (the recall
   gate is RED at 0.816 < 0.87). The wiring is complete; the default is gated off.
