**Verdict: PASS.** The paper's deterministic title matcher is ported as a pure,

## Matcher parity (semantic, not byte)
Ported from `tools/paper/decompose_exposure.py` (`normalise`/`gold_hit`, itself
verbatim from `bench_ontology_uplift.py`):
- `normalise` = lowercase + replace every non-`[a-z0-9\s]` run with a single space
  + collapse whitespace + trim (chained `_PUNCT_RE.sub` then `_WS_RE.sub`).
- `title_hit` = normalised-title substring of the text, OR ≥ 80% of the title's
  length-≥4 words present as whole words.
Served titles = the seeds' resolved class titles + serialised relation-target
titles, FILTERED to those present in the served block (same matcher) — i.e. "what
the model saw", robustly, without markdown parsing. O(targets × answer).

## Response shape
The `exposure` block lives inside Loom's own additive `loom` telemetry namespace
(OpenAI-standard fields untouched). Per the mission, exposure telemetry is ALWAYS
emitted when a scaffold was injected; only the content-mutating "Not covered" line
is gated by `LOOM_EXPOSURE_APPEND`. Not-engaged responses carry `exposure:null`.
(Adversarial-audit finding 2 flagged the added telemetry fields; accepted as
by-design per the mission mandate — see AUDIT record.)
