# EXP-012 — F1 verbatim serving mode

**Verdict: PASS.** With `LOOM_VERBATIM_MODE=1` and a delivery-lookup request over a
high-confidence scaffold, `/v1/chat/completions` returns a valid OpenAI chat
completion built from the scaffold's canonical markdown WITHOUT calling the
backend. All gating edge cases (opt-out, multi-turn, streaming, threshold) fall
through to delegation; default-off preserves current behaviour.

- base git SHA: 328f697 (pre-commit working tree)
- crates touched: loom-domain (`ServedMode`), loom-facade (`serving.rs`, `routes.rs`, `config.rs`)

## Design decisions
- **`ServedMode {Delegated|Verbatim}` (new domain enum), NOT a `FusionPath::Verbatim`
  variant.** `FusionPath` is the RETRIEVAL axis (which index produced candidates);
  a verbatim serve is still a `LexicalHit`. Overloading it would conflate retrieval
  with delivery and perturb every existing `FusionPath` serialisation/test. The two
  axes now serialise side-by-side in the `loom` telemetry (`fusion_path` +
  `served_mode`). Invariant I-P1 respected: the domain crate owns the type; the
  façade only decides + shapes.
- **Threshold semantics + default = 8.0.** Compared against the scaffold `top_score`
  on the LEXICAL additive scale (`match_`): `EXACT_TITLE_WEIGHT`=8.0 per
  exactly-matched title word, `MIN_SEED_SCORE`=2.0 inject floor,
  `STRONG_MATCH_SCORE`=8.0 a strong exact single-word title hit. 8.0 ⇒ "serve
  verbatim only on a full exact-title match" (conservative: paraphrase/overlap-only
  hits score below 8 and delegate). Profile A sets 8.0.
- **Opt-out `{"loom_options":{"verbatim":false}}`** is a properly-parsed request
  field, stripped from the delegated body so a strict backend never sees it.
- **Streaming + multi-turn bypass** verbatim and delegate as today. Multi-turn =
  any prior assistant message; delivery-lookup shape = last message user + no
  assistant turns.

## Proof technique
The default test builder wires a retrieval-only backend (empty
`DISTILL_BACKEND_URL`). A **200** on an eligible request PROVES no backend was
called (verbatim); a **503** (`NoBackend`) PROVES it fell through to delegate. So
the 200-vs-503 status cleanly witnesses which path ran — `f1_verbatim_serves_without_backend`
(200) vs `f1_opt_out|multi_turn|streaming|threshold` (503).
