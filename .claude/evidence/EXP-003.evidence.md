## What is asserted

`InjectionPolicy::effective_budget(top_score, requested)` matches the Python
`scaffold()` gate branch (`app/ontology_scaffold.py:437-450`) exactly, across the
table axes: `confidence_injection` on/off × `top_score` below / at / above
`MIN_INJECT_SCORE` and `STRONG_MATCH_SCORE`, including the `MIN_INJECT_FRACTION`
clamp. Computed in `f64` (Python `float`), so the `int(budget * frac)`
truncation is bit-identical.

| test | axis | expectation |
|---|---|---|
| `gate_off_returns_full_budget_regardless_of_score` | injection OFF | `Some(requested)` for any score (Python baseline) |
| `gate_on_below_min_skips` | top < MIN_INJECT_SCORE | `None` (skip injection) |
| `gate_on_at_or_above_strong_full_budget` | ratio ≥ 1.0 | frac clamps to 1.0 → full budget |
| `gate_on_midrange_scales_budget` | top 4.0 / 6.0, strong 8.0 | 1500·0.5=750, 1500·0.75=1125 |
| `gate_on_fraction_floor_clamps` | top 2.0 → ratio 0.25 < 0.4 | clamp UP to 0.4 (`≠` the un-clamped 0.25 result) |
| `gate_on_strong_zero_avoids_div` | strong ≤ 0 | frac stays 1.0 (Python divide guard) |
| `gate_on_min_one_budget_floor` | tiny requested | `max(1, floor)` keeps ≥ 1 token |

## Divergence note (Python wins)

`RUST-ARCHITECTURE.md` §5.4 sketches `effective_budget` in `f32`. The port uses
`f64` because Python does — this makes the score ordering and the
`int(budget*frac)` truncation exact. The public signature therefore takes
`f64`, not the doc's `f32`.
