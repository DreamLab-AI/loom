## 6. DIVERGENCES (SOURCE / empirical reality wins — noted per mission rule)

1. **Design recall floor 0.87 vs measured 0.816 (rgb-protocol).** §8.4 specifies
   cosine ≥ 0.87 for the in-domain query. The stored vectors are concept-**document**
   embeddings (title+definition+prose), so a short query "rgb protocol" lands at
   0.816 — `rgb-protocol` is in the top-2 but does not clear 0.87. This is NOT a
   wiring bug (the ANN, ID mapping, and cosine math are all correct); it is the
   real recall of short-query-vs-document-embedding in this corpus. Per ADR-136 D3
   this keeps the recall gate RED and `LOOM_SEMANTIC_FALLBACK` at its default `0`,
   which is the designed state. **Team decision needed:** recalibrate the floor to
   the document-embedding regime (~0.80), or embed a query-shaped field per class,
   before flipping the fallback on. The test therefore hard-asserts a wiring floor
   (0.75, well below measured, well above the decoy band) and prints the 0.87
   verdict rather than faking a pass.

2. **Decoy 0.5153 is close to the 0.55 ceiling.** The off-ontology decoy's top
   hit (`groth-16`) sits just under 0.55. The dynamic range of these
   document-embeddings is compressed; any bench-set `LOOM_SEMANTIC_MIN_INJECT`
   should sit around ~0.60–0.70, not near 0.55. Recorded for the WS-O bench.

3. **Embedding column type is `ruvector`, not pgvector `vector`.** The exporter
   reads `embedding::text` and parses the bracketed float list (robust for any AM
   output function). `pgvector` remains a declared `pg-write` dependency for the
   future delta-diff `PgWriter` promote path (§11.2), not used on this bootstrap.

4. **`ruvector-core` crate version is 2.0.5** (the CLI on PATH is 0.2.35); the
   path-dep resolves to the workspace source at `../ruvector/crates/ruvector-core`.
   API matches the source I read; `SearchResult.score` for Cosine is a DISTANCE
   (`1 − cos_sim`), mapped to a similarity in [0,1] in `nearest()`.
